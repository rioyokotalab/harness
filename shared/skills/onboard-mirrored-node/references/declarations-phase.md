# Declaration phase

After explicit `go`, reconstruct the ledger plan and read the declaration
contract. Generate required declarations in a staging worktree or other
non-live surface. Never overwrite a declaration;
reject ambiguous OS, scheduler, quota, filesystem, root, symlink, or schema
state instead of guessing.

Validate exact changed-context onboarding owners, shell syntax, fixture
privacy, map uniqueness, and exact diff. Run a complete suite only on an
explicit owner request. Commit only intended files. Fetch and reconcile again;
push only with owner or repository authority.
