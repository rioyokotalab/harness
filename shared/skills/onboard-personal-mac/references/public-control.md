# Public control plane

Run `macos-control --host HOST --plan|--apply` from the verified public
checkout. Install or validate only the declared Codex, Claude, agent-skill,
repository, and Homebrew Bash launcher links. Never replace an owner path,
adopt an unexpected file, or let a public link disclose private companion
state.

Require the plan to identify every destination, current identity, source, and
rollback. After apply, verify each discovery link with native resolution from
a fresh process; do not reload the owner's active shell or tmux server.
