# Reconstruct and plan one Mac

1. Read the closest `AGENTS.md`, compact `TODO.md`, selected task record,
   `docs/personal-macos.md`, `docs/personal-macos-config-sync.md`, and active
   personal-Mac sections of `docs/plans/personal-macos-fleet.md` completely.
2. Resolve the current published commit and applicable native commands from
   the repository. References define ordering and refusal gates, never frozen
   versions.
3. Require exactly one owner-supplied SSH/logical host. If none was named, ask
   only for that identifier. Never list private profiles or inspect SSH keys
   to discover it.
4. Perform value-free, read-only discovery through recognizable native Git,
   SSH, macOS, and Harness commands. Verify transport, logical identity,
   architecture, current-user ownership, public/private checkout cleanliness,
   native agent ownership, and absence of transaction or artifact collisions.
   A private Mac logical ID requires the repository's private Mac validator;
   never fabricate a public Linux profile.
5. Run the aggregate plan with `macos-pilot-plan --host HOST`. Treat every
   `BLOCK`, schema mismatch, unexpected prompt, failed query, and private
   curation boundary as unresolved.
6. Checkpoint one host-specific plan in the selected task record: confirmed
   facts, assumptions, selected components, owner defaults, blockers, rollback,
   validation, publication, and exact next command. Change `TODO.md` only for
   queue-level phase, order, summary, or record-pointer changes.

Ask one material decision at a time. Set `ready-for-go` only after every
material choice and refusal is resolved, then wait for the owner's explicit
`go`. Planning and discovery are read-only.
