## Objective

Prevent verified task-worktree archives from growing without bound while
preserving exact rollback, interrupted-closeout recovery, unpublished work,
and repository independence. Optimize future storage and audit cost, not a
one-time deletion count.

## Acceptance

- A read-only inventory maps every bundle, receipt, plan, manifest, apply
  state, exact tip, owning repository, ledger reference, age, reachability, and
  sole-copy status without inspecting Personal payloads.
- Retention is fail-closed: active/unpublished tips, incomplete transactions,
  referenced evidence, unknown ownership, and the newest independent recovery
  generation are never candidates.
- Any compaction preserves exact refs in a newly verified bundle, proves a
  restore before cleanup, and uses immutable guarded manifests with
  post-delete archive and repository audits.
- Policy distinguishes redundant merged-task rollback from disaster-recovery
  generations and sets a measured size/age trigger; it does not use age or
  ancestry alone.
- Focused archive/housekeeping tests and clean Harness phase one pass. No
  remote branch, managed session, ruleset, approval count, credential, backup
  scheduler, or sibling repository is changed.
