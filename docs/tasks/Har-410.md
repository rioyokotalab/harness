# Har-410 — Make the Harness ledger integration check state-aware

the ordinary selector to be idle even though the focused ledger contract
explicitly permits and selects an active ordinary task. This made every valid
in-progress Harness task fail the complete integration gate.

idle, or one selected `Har-NNN` task. The synthetic owning tests continue to
prove exact active-task selection and idle behavior. Direct ledger validation
