## Safety gates, validation, and rollback

- Unsafe SSH identity, changed preimage, missing agent, ambiguous route, dirty
  checkout, divergence, unreviewed policy, or failed hosted check stops its stream.
- No private SSH, credential, pane, transcript, or sibling data enters Harness.
- No existing Local tunnel is stopped, signaled, renamed, or overwritten.
- Hub acceptance requires t4-origin value-free route results, Riken reverse
  reachability, exact clean repository tips, sentinel doctor success, and no
  residual transfer/staging artifacts.
- Rollback removes only verified failover state, restores sentinel links through
  agent-config, and preserves project checkouts absent guarded cleanup authority.
