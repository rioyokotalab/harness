## Reproduced defect

The validator deliberately permits the mutable index disposition to diverge
from an immutable packet's publication-time `state`, but selector output and
cold-start instructions did not name that distinction. A consumer therefore
treated Per-015's old `gated` packet metadata as current after the producer
index was `ready`. Separately, `check-producer-diff` allowed modification of an
already-published packet, so the mistaken repair passed validation.
