   windows `codex` and `claude`.

   treats as a separate authority boundary. Confirm a launchd agent is wanted,

   tunnel-watchdog pattern) instead.

   mode. Confirm this includes accepting the one-time per-machine

   acceptance rather than a flag.
4. **Injection blast radius.** Should the Claude injection route be
   send-only initially, or include the acceptance-critical `request` and
   `fallback` routes from day one? Default proposal: `send` only, then extend.
