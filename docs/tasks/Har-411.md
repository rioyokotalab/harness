# Har-411 — Exclude private targets from credential-policy pinning

The first Har-403 credential validator pinned a digest of the complete broker
profile. Exact-resource profiles contain private target values, so computing
that digest would violate the frozen rule against hashing those values even
though the digest itself disclosed no plaintext.

The successor digest covers only credential-relevant policy: profile and
service identity, client parity, provider contract, capabilities, scopes,
socket, and write mode. Resource policy and every resource value are excluded;
target authorization remains enforced from the live profile. A focused
regression proves two profiles differing only in private resources produce the
same credential-policy digest.
