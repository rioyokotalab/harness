# Har-415 — Bound Slack provider results to the broker wire envelope

Har-403's Swallow Web API design review found that a profile may accept an
upstream response larger than the broker's 64-KiB newline-delimited JSON-RPC
envelope. The server currently wraps that value and only discovers the excess
inside `write_message`, which terminates the client connection instead of
returning a stable value-free tool error.

Measure the final encoded response before it reaches the socket. Return a
small `provider-result-too-large` tool failure when the envelope would exceed
the fixed bound, without preserving any provider bytes. Cover the exact limit
behavior with a focused synthetic regression, then validate it together with
the Swallow adapter under Har-403's final Slack and integrated gates.
