# Research policy

Read this file completely before the matching action selected by root
`AGENTS.md`.

- Prefer primary sources and reproducible measurements. Record provenance and
  environment details; never generalize from an inference or one benchmark.
- Freeze a correct baseline before optimization. Compare matched runs and keep
  correctness, numerical, scaling, and regression evidence.
- For people and projects, report evidence, risks, dependencies, and next
  actions—not inferred motivation, ability, or private-sensitive detail.
