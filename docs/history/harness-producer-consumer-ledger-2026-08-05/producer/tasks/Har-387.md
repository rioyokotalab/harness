equivalent repository-local work for Personal, Students, Swallow, and Website.
The selector is the sole current-disposition authority. Packet metadata remains
immutable after publication. Producer diff validation may add a new packet but
must reject modification, deletion, rename, or type change of a packet already
present in the protected base.

Restore Per-015's packet to its exact originally published byte before enabling
the new Personal guard. Preserve Personal's active consumer checkout and all
unrelated work. Keep every repository independent; do not place private task
content in Harness and do not weaken review, validation, privacy, or writer

disposition output plus fail-closed immutable-packet diffs. Repository-local
instructions state that packet `state` is publication-only and never overrides
`next-ready`. Each affected repository has an independent durable task and
protected publication route; a blocked repository does not block the others.
No consumer writes are mixed with producer-owned queue changes.
