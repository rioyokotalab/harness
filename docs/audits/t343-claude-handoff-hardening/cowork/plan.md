## Risks and recovery

- A Claude tool-policy flag can parse yet be ineffective. Record native CLI
  help and event evidence; never infer confinement from prose or settings
  alone.
- Claude permissions are not an OS sandbox. Use the available environment
  sandbox for write experiments, stage only bounded public-safe inputs, and
  retain external seals and recoverable baselines.
- An acknowledged model row, stage import, Git publication, or refresh is not
  idempotent. Never replay it after ambiguous or successful acknowledgement;
  reconcile read-only and assign a distinct identity when retry remains safe.
- A failing full suite can expose an unrelated or environment-only gate.
  Preserve exact output, prove target state, push the issue LIFO, and change
  only the demonstrated cause.
- A structurally importable co-pilot document is not proof that its commands
  ran. Apply the evidence contract selected by the packet's authority class
  and independently reproduce at least one deterministic execution record.
- No raw recursive or multi-path deletion. Task-owned tree cleanup uses
  `guarded-delete`; exact single files are unlinked only after identity checks.
- Rollback for repository changes is a protected revert of the smallest
  coherent commit. Existing historical benchmark reports and unrelated
  worktrees are immutable preservation anchors.
