For each repository, record protected revision, primary branch/worktree state,
open task work, local branch/worktree/temp residue counts, producer/receipt
consistency, and the native validation route. Measure:

1. root instructions plus producer entrypoint bytes;
2. selected packet, board, and matching record bytes;
3. only routed policy and skill bytes;
4. executed action groups and elapsed wall time; and
5. focused and integrated validation duration.

An optimization is acceptable only when the same cold-start, writer-boundary,
privacy, interruption, and publication capabilities pass while at least one
measured cost improves and no material cost regresses.

## Rollback and publication

Every repository uses its own branch, worktree, validation, and protected PR.
Producer-owned and consumer-owned changes never share a diff boundary. A
blocked repository does not hold another stream. A published schema defect is
reverted through protected Git while preserving packets and receipts as
history. Ambiguous worktrees, refs, receipts, or external writes are preserved.
